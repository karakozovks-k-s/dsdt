# Эвал-задача 01: `is_ignored` — матчер `.gitignore`

> Размер решения: ≤ 100 строк. Сложность — в трёх местах, на которых
> валятся «vibes-based» решения.

## Что нужно сделать

Реализовать функцию:

```python
def is_ignored(patterns: list[str], path: str, *, is_dir: bool = False) -> bool:
    ...
```

Положить в **`solutions/gitignore.py`**.

- `patterns` — строки из `.gitignore` в исходном порядке.
- `path` — относительный путь через `/`, без ведущего слэша
  (например, `"src/a.log"`).
- `is_dir` — путь это директория или файл.

## Контракт (подмножество gitignore)

1. Пустые строки и строки, начинающиеся с `#`, — пропускаются.
2. Trailing `/` → паттерн матчит **только директории**.
3. Leading `/` → якорь к корню. Без него — матч на любой глубине.
4. `*` матчит что угодно **кроме `/`**. `?` — один символ, не `/`.
5. `**` как сегмент пути матчит **ноль или больше** сегментов:
   - `foo/**` — всё внутри `foo`,
   - `**/foo` — `foo` на любой глубине,
   - `a/**/b` — `a/b`, `a/x/b`, `a/x/y/b`.
6. Если в паттерне есть `/` где-то **кроме trailing** — он **якорный**
   (от корня). Если `/` нет вовсе — матч на любой глубине
   (`*.log` → `src/x.log` ✓).
7. Префикс `!` — негация. **Побеждает последний совпавший паттерн**, не первый.
8. По умолчанию — не игнорируется.

## Где ловушки (это и тестируется)

- **«Последний матч побеждает»**, а не первый. Половина наивных решений
  пишет `for p in patterns: if match(p): return True` — и фейлит на
  кейсах с негацией.
- **`*` не должна матчить `/`**. Решения через стандартный `fnmatch`
  здесь падают.
- **`**` с нулевым числом сегментов** — `a/**/b` обязано матчить `a/b`.
- **Якорность по наличию `/`** — `foo/bar` якорное, `bar` нет, `bar/`
  не якорное (но dir-only), `foo/bar/` якорное И dir-only.
- **`is_dir=False` против паттерна с trailing `/`** — не матчит, даже
  если имя совпало.

## Антипаттерны при ревью

Если в решении видите — это плохие сигналы:

- `import fnmatch` — почти наверняка `*` будет есть `/`.
- `for p in patterns: ... return True` без отслеживания «последнего
  матча» — фейл на негации.
- `re.compile(pattern)` без эскейпинга `.`, `+`, `(`, `)` в исходных
  путях — будет ложный матч.
- Любая попытка читать `os.path` или файловую систему — задача чисто
  алгоритмическая, ввод-вывод запрещён.
